# Python农产品价格预测系统

## 核心功能
- 数据分析：基于tensorflow全国农产品价格分析
- 数据可视化：展示全国农产品价格的整体情况，包括平均价格、最高价格、最低价格等指标
- 价格趋势分析：折线图展示农产品价格的历史变化趋势
- 价格变化滚动表：表格形式展示农产品价格的变化情况
- 柱状图展示：不同农产品价格的变化情况
- 雷达图对比：不同农产品价格的对比情况
- 饼图展示：最低价格的变化情况
- 价格预测：使用深度学习模型LSTM预测未来7日价格走势
- 用户查询：通过农产品名称查询价格信息

## 适用场景
- 农产品价格监控
- 农产品市场分析
- 农业生产决策支持
- 投资决策参考

## 技术特点
- 使用TensorFlow深度学习模型进行价格预测
- 结合Python、Pandas、NumPy等数据处理技术
- 前端采用HTML、CSS、JavaScript等技术开发
- 数据可视化使用ECharts工具
- 系统架构清晰，界面简洁美观
